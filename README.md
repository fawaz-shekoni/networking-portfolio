# Packet Tracer Networking Portfolio

A guided series of 31 networking builds, from small LANs to secure multi-site and IoT designs. Each entry has a fresh project title and a practical goal. Build and document your own topology, configuration, tests, and lessons learned.

## How to use this portfolio

- Create a writeup for each build in `projects/`, using `projects/TEMPLATE.md`.
- Save Packet Tracer files in `packet-tracer/` with names such as `project-01-network-foundations.pkt`.
- Add clear topology screenshots to `images/`, such as `project-01-topology.png`.
- Link each lab and its screenshots from the corresponding writeup.
- Keep passwords, personal details, and real network information out of published files.
